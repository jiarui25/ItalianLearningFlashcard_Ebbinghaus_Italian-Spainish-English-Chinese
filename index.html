一、产品定义

爱斯宾浩是一款面向多语种词汇记忆的间隔重复（Spaced Repetition）学习工具。核心目标：把「复习时机」交给算法，用户只需判断记不记得。在此基础上叠加两项附加能力：意大利语发音与英 / 中 / 西 / 意 四语互译。

本版本为可运行的单文件 Web 原型（无后端、数据存于 localStorage），用于验证交互与调度逻辑。

功能模块

① 复习引擎
艾宾浩斯间隔序列、等级升降、到期队列、复习历史
② 卡片库
一词多语释义、状态标签、下次复习时间、增删
③ 语音层
Web Speech API；按语言匹配 voice，意大利语优先保障
④ 翻译层
四语两两互译，带缓存；支持手动兜底
⑤ 可视化
理论遗忘曲线 + 实测留存率对照

二、核心算法：艾宾浩斯复习调度

采用固定间隔序列（秒）：300 → 1800 → 43200 → 86400 → 172800 → 345600 → 604800 → 1296000 → 2592000 → 7776000，即 5 分 / 30 分 / 12 时 / 1 天 / 2 天 / 4 天 / 7 天 / 15 天 / 30 天 / 90 天。每张卡片维护 level（当前间隔档位）：

用户反馈等级变化下次复习留存统计
😎 记住 (good)level + 1（上限 L9）序列下一档记为「记住」
🤔 模糊 (mid)level − 1（下限 L0）退回上一档记为「未记住」
😵 忘了 (bad)归零 L05 分钟后记为「未记住」

局限：固定序列未考虑个体差异（记忆强度 S）。生产环境建议迁移到 SM-2 / FSRS，按每张卡片的难度与稳定性动态计算间隔。

三、附加能力实现

能力方案约束
意大利语发音SpeechSynthesis，lang = it-IT，优先选取系统 it-IT voice依赖操作系统/浏览器内置语音包；检测中…
四语互译MyMemory REST，langpair = src|tgt，结果按 (src,tgt,text) 缓存公共接口有速率与配额限制；需联网
任意语言朗读同上，en-US / zh-CN / es-ES / it-IT 四套 voice中文 TTS 在部分环境可能缺失
数据持久化localStorage（单键 JSON）仅本机单浏览器，无云同步

四、后续迭代优先级

  1. 调度升级：FSRS 动态间隔 + 每日学习量上限，替代固定序列。
  2. 语音可靠性：接入离线/云端 TTS 音频（如 Azure / Edge TTS），消除对本地语音包的依赖，并支持语速调节。
  3. 翻译可靠性：替换为正式翻译 API 并支持批量回填，加入离线词库兜底。
  4. 数据层：账号 + 云同步，支持多设备与导入导出（CSV / Anki）。
  5. 学习形态：听写模式、例句、反向卡片（意→中 / 中→意）。
